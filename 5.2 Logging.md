# Log

Un log (o registro, en español) es un archivo de texto secuencial y cronológico que almacena automáticamente eventos, acciones, errores o mensajes de funcionamiento dentro de un sistema informático, aplicación o red. 

## Logs en kubernetes

- Ver logs en un container

```sh
kubectl logs <pod-name>
```

- Ver logs en un container en específico

```sh
kubectl logs <pod> -c <container>
```

- Ver logs en tiempo real

```sh
kubectl logs -f <pod>
```

## ¿Dónde se guardan los logs?

Los logs se almacenan en el nodo (worker) donde corre el Pod:

```sh
/var/log/containers/
```

Internamente:

- El runtime (como containerd o Docker) guarda los logs
- Kubernetes solo los expone
