# RBAC

La autorización RBAC en Kubernetes (Role-Based Access Control) es el mecanismo principal para decidir quién puede hacer qué dentro del cluster.

En lugar de dar permisos directamente a usuarios, RBAC funciona con roles + asignaciones.

**Componentes de RBAC**

Vamos a utilizar Role con RoleBinding y ClusterRole con ClusterRoleBinding para asginar los permisos

- Role: Define permisos dentro de un namespace
- ClusterRole: Define permisos a nivel cluster o global

## Ejemplo

### 1. Role & RoleBinding

Permisos dentro de un namespace

```yaml
kind: Role
apiVersion: rbac.authorization.k8s.io/v1
metadata:
  namespace: default
  name: pod-reader
rules:
- apiGroups: [""]
  resources: ["pods"]
  verbs: ["get", "list"]
```

Asocia un Role a un usuario/grupo/service account (en un namespace)

```yaml
kind: RoleBinding
apiVersion: rbac.authorization.k8s.io/v1
metadata:
  name: read-pods
  namespace: default
subjects:
- kind: User
  name: juan
roleRef:
  kind: Role
  name: pod-reader
  apiGroup: rbac.authorization.k8s.io
```

### 2. ClusterRole & ClusterRoleBinding

Permisos a nivel cluster o global

```yaml
kind: ClusterRole
apiVersion: rbac.authorization.k8s.io/v1
metadata:
  name: node-reader
rules:
- apiGroups: [""]
  resources: ["nodes"]
  verbs: ["get", "list"]
```

Asocia un ClusterRole a nivel cluster

```yaml
kind: ClusterRoleBinding
apiVersion: rbac.authorization.k8s.io/v1
metadata:
  name: read-nodes
subjects:
- kind: User
  name: juan
roleRef:
  kind: ClusterRole
  name: node-reader
  apiGroup: rbac.authorization.k8s.io
```

## Conceptos clave

Verbs (acciones)

- get → leer uno
- list → listar
- watch → observar cambios
- create
- update
- patch
- delete

Resources

- pods
- deployments
- services
- nodes
- etc.

apiGroups

- "" = core (pods, services)
- "apps" = deployments
- "batch" = jobs

**¿Cómo funciona paso a paso?**

Cuando haces una request:

```sh
kubectl get pods
```

Kubernetes evalúa:

#### 1. Identidad

- Usuario: tú (o ServiceAccount)
- Grupo (si aplica)

#### 2. Acción

- Verbo: get
- Recurso: pods
- Namespace: default

#### 3. RBAC busca reglas

Busca:

- RoleBindings en ese namespace
- ClusterRoleBindings globales

#### 3. Decisión

✔ Si encuentra una regla que permita → acceso OK

❌ Si no → Forbidden
