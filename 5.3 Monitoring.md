# Monitoring

## Metric Server

El Metrics Server es un componente que recolecta métricas básicas de uso de recursos (CPU y memoria) de los Pods y nodos, y las pone disponibles dentro del cluster.

El flujo es así:

1. Cada nodo tiene un kubelet
2. El Metrics Server consulta al kubelet
3. Recoge métricas como:
   - CPU
   - Memoria
4. Expone esas métricas a través del API de Kubernetes

El Metrics Server es clave para: Horizontal Pod Autoscaler (HPA)

Entrega métricas en tiempo real y básicas:

- CPU usage
- Memory usage

## Comandos

Despues de instalar el metric server podemos usar los siguientescomandos

- Para ver las metricas de los pods

```sh
kubectl top pods
```
- Para ver las metricas de los nodos

```sh
kubectl top nodes
```
