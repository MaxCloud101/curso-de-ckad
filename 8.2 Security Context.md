# Security Context

El securityContext en Kubernetes es la forma de definir cómo se ejecuta un contenedor o un Pod desde el punto de vista de seguridad: usuario, permisos, privilegios, sistema de archivos, etc.

Por defecto, muchos contenedores podrían correr con permisos altos (incluso como root). El securityContext evita que tu contenedor corra con más privilegios de los necesarios

Puede estar en dos niveles:

- A nivel de Pod
- A nivel de contenedor

```yaml
spec:
  securityContext:        # nivel Pod
  containers:
    - name: app
      securityContext:    # nivel contenedor
```

## Propiedades más importantes

### 1. runAsUser / runAsNonRoot

```yaml
securityContext:
  runAsUser: 1000
  runAsNonRoot: true
```

- **runAsNonRoot: true** Verifica que el contenedor no corra como root
- **runAsUser: 1000** Asigna el UID del contenedor

### 2. allowPrivilegeEscalation

```yaml
securityContext:
  allowPrivilegeEscalation: false
```

- Bloquea sudo y escalamiento de permisos

### 3. capabilities

```yaml
capabilities:
  drop:
    - ALL
```

- Quita todos los permisos innecesarios
- capabilities solo se puede definir a nivel de container, no a nivel de Pod.

**Capacidades  más usadas:**

Red
- NET_BIND_SERVICE → usar puertos bajos (80, 443)
- NET_ADMIN → cambiar configuración de red (⚠️ peligroso)

Sistema de archivos

- DAC_OVERRIDE → ignorar permisos de archivos
- CHOWN → cambiar dueño de archivos

Procesos / seguridad

- SETUID / SETGID → cambiar de usuario/grupo (⚠️ relacionado con escalación)
- SYS_ADMIN → súper poderosa (⚠️ casi root)

**Importante**

Algunas capacidades son muy peligrosas, por ejemplo:

- SYS_ADMIN → prácticamente control total del sistema
- NET_ADMIN → manipular red
- SETUID → potencial escalación de privilegios

Evítalas salvo que sea estrictamente necesario.

**Ejemplo:**

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx-cap-example
spec:
  containers:
    - name: nginx
      image: nginx:latest
      ports:
        - containerPort: 80
      securityContext:
        runAsNonRoot: true
        runAsUser: 1000
        allowPrivilegeEscalation: false
        capabilities:
          drop:
            - ALL
          add:
            - NET_BIND_SERVICE
```
