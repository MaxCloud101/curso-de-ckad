# Security Context

El securityContext en Kubernetes es la forma de definir cómo se ejecuta un contenedor o un Pod desde el punto de vista de seguridad: usuario, permisos, privilegios, sistema de archivos, etc.

Por defecto, muchos contenedores podrían correr con permisos altos (incluso como root). El securityContext evita que tu contenedor corra con más privilegios de los necesarios

Puede estar en dos niveles:

- A nivel de Pod
- A nivel de contenedor

```yaml
spec:
  securityContext:        # nivel Pod
  containers:
    - name: app
      securityContext:    # nivel contenedor
```
