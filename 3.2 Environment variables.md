# Environment variable

Las variables de entorno (environment variables) sirven para pasar configuración a tus contenedores sin modificar el código. Es una de las formas más usadas para manejar configuración en apps (URLs, credenciales, modos de ejecución, etc.).

- Definicion en YAML

```yaml
env:
  - name: ENV
    value: "prod"
```

- Equivalencia

```
ENV=prod python app.py
```
## Ejemplo

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: ejemplo-env
spec:
  containers:
    - name: app
      image: nginx
      env:
        - name: MI_VARIABLE
          value: "hola"
```
